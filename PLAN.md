## Этап 2 — остаток

### Шаг 3 — Stack: акценты крупнее + зеркальный слева
`components/stack-accent.tsx` получает проп `side?: "left" | "right"`.

- **Зеркалить через `scale-x-[-1]` на `<svg>`, не на `<g>`.** GSAP владеет трансформом
  `.accent-group`; Tailwind v4 компилирует `scale-x-*` в отдельное свойство `scale:`,
  которое **перемножится** с `transform` от GSAP.
- Разные длительности (14s / 18s) — синхронная пара читается как прелоадер.
- Размер 96/112px → 144/208px, но **радиусы мятного и жёлтого кружков в viewBox
  уменьшить** (10→8, 7→5.5), а нейтральный квадрат увеличить. Иначе акцентные цвета
  вырастают в «крупную поверхность», что контракт запрещает.
- `stroke="#c6c6c6"` → `stroke="currentColor"` + `text-line` на обёртке.
- **Риск наложения реальный и узкий.** Заголовок отцентрован в `max-w-[46ch]`
  (~700–900px в Anton); свободного места по бокам: 1280px → ~130px, 1536px → ~240px.
  Поэтому левый акцент — **только `xl:` и выше**, ниже по секции (не зеркальными
  «книжными подпорками»), плюс `relative z-10` на заголовок и группы чипов.

### Шаг 4 — Services: карусель → сетка 3×2 со скользящим блоком
- `lib/content.ts`: шестая услуга — **Process automation** (API, очереди, шедулеры,
  дашборды). Её же добавить в `footer.columns[0]`.
- `components/services.tsx` → снова **серверный** (шапка секции), новый
  `components/services-grid.tsx` (`"use client"`) — сетка.
- Карточки: `sm:grid-cols-2 lg:grid-cols-3`, прозрачные с хайрлайном `border-line`,
  **без** `bg-paper`. Скользящий блок — `bg-carbon`. Тот же мотив, что у чипов в Stack.
- Активной карточке вешать класс `tone-dark` — она сама перекрасит потомков через
  `--color-fg/muted/faint/line`. Бонус: `:focus-visible` станет белым сам.
- **Замер позиции — `offsetLeft/offsetTop`, не `getBoundingClientRect()`.** `Reveal`
  ставит `y: 24` (rect вернёт сдвинутую позицию), `#smooth-content` трансформирован
  (rect зависит от скролла и отстаёт), а `offset*` считается от `offsetParent`.
- **Анимировать `x/y/width/height`, не `scale`** — неравномерный scale расплющит
  `rounded-card` в эллипс (уже задокументировано в `scroll-panel.tsx:84`).
- Первое появление — `gsap.set` + отдельный fade, иначе блок влетает из угла.
  На уход — гасить opacity, геометрию не трогать.
- Ховер под `HOVER_OK` (делегированный `pointerover`), **фокус под `MOTION_OK`** —
  клавиатурника на тач-ноутбуке нельзя лишать подсветки.
- Fallback для reduced-motion: `data-slider` ставится **только внутри** `HOVER_OK`-ветки,
  в CSS живёт `.services-grid:not([data-slider]) .service-card:hover`. Тот же идиом, что
  `[data-fill]`. Атрибут снимать руками в cleanup — `mm.revert()` откатывает твины, не записи.
- После шага удалить `lib/use-drag-scroll.ts` (потребителей не остаётся).

### Шаг 5 — Product: пословное проявление при скролле
- Новый `components/product-copy.tsx` (`"use client"`), `product.tsx` остаётся серверным.
  **Компонент не должен иметь состояния и ре-рендериться** — SplitText переписывает
  `innerHTML`, ре-рендер React этот DOM снесёт.
- `SplitText.create(paragraphs, { type:"words", tag:"span", aria:"auto", autoSplit:true, onSplit })`.
  `tag:"span"` обязателен — дефолтный `div` внутри `<p>` невалиден. `aria:"auto"`
  обязателен — иначе скринридер получит 60 разрозненных слов. Триггер строить
  **внутри `onSplit`** и возвращать таймлайн оттуда. `mm.revert()` не откатывает
  SplitText → в cleanup нужен `split.revert()`.
- **Конфликт с `.reveal`:** сейчас `.reveal` стоит на `h2`, на **каждом `<p>`** и на
  обёртке CTA. Батч пишет opacity на родителей, скраб — на их детей, значения
  перемножатся. Убрать `.reveal` с обоих `<p>` и с CTA, оставить на `h2` и на колонке с фото.
- **Цвет через `opacity`, не через `color`.** Слова наследуют `text-fg` (в `.tone-dark`
  это `#ffffff`); старт с `opacity: 0.18` даёт на чёрном ≈`#2e2e2e` — это и есть
  «тёмно-серый», совпадает с `--color-graphite`. Ноль захардкоженных hex.
  **`will-change` не ставить** — 60 промотированных слоёв это то, от чего `reveal.tsx`
  специально избавлялся.
- Скраб: `trigger` — текстовая колонка, `start: "top 78%"`, `end: "bottom 60%"`,
  `scrub: 0.15`, `invalidateOnRefresh: true`. Не `end: "+=80vh"`: колонка ~500px, и тогда
  последнее слово досветится ровно когда колонка уходит за верх экрана.
  `stagger: { amount: 4 }` (общий разброс, не на слово). CTA стартует на `">-0.1"`.
- Гейт `WORD_SCRUB_OK = "(min-width: 768px) and (prefers-reduced-motion: no-preference)"`
  в `lib/motion.ts`. На телефоне колонка часто выше экрана, а `smoothTouch:false` +
  `ignoreMobileResize:true` означают, что ресайз от адресной строки не вызовет refresh.
- `if (!isDocumentVisible()) return;` — **первой строкой** внутри `mm.add`, выше
  `SplitText.create`. Плюс пояс в CSS:
  `@media (prefers-reduced-motion: reduce) { .pw { opacity: 1 !important } }`.
- После пере-сплита (шрифты через `next/font` с `display: swap`) — **отложенный через rAF
  и дедуплицированный** `ScrollTrigger.refresh()`. Синхронно внутри `onSplit` звать нельзя.

### Шаг 6 — логотип и фавикон

**Блокер, чинить первым:** у обоих SVG **нет `viewBox`**, а надпись лежит в полосе
x 45–860, y 455–745 внутри пустого холста 896×1200. Без `viewBox` SVG не масштабируется:
на высоте 44px графика окажется за пределами вьюпорта и отрисуется **пусто**.
Добавить общий для обоих `viewBox="40 448 816 300"` — общий, чтобы марка не дёргалась
на пару пикселей при смене тона.

**Переименовать файлы.** `Untitled - 23 августа 2026 г. в 15.04.50.svg` — не косметика,
а риск деплоя: macOS хранит имена в NFD, URL кодирует NFC, статика на Linux/Vercel
нормализацию не делает → локально работает, в проде 404.

**Рендер: один файл + CSS `mask-image`.** Тёмный файл имеет одиннадцать заливок
`#010101`–`#0B0B0B` (перцептивно одно и то же), маска использует **альфу**, значения
fill ей безразличны:

```css
.brand-mark {
  mask-image: url("/logo/wordmark.svg");
  -webkit-mask-image: url("/logo/wordmark.svg");
  mask-repeat: no-repeat; mask-size: contain; mask-position: center;
  background-color: currentColor;
}
```

У навбара уже есть `.nav-brand { color: var(--nav-brand-fg); transition: color .4s }` —
смена тона будет мгновенной, только на CSS, без JS и без второго запроса. Светлый файл
не нужен: у него хуже трассировка (крапины `#929292`/`#A7A7A7`/`#ABABAB`/`#C7C7C7`,
на 44px читаются как грязь).

**Риск `--nav-height`.** Высоту бара задаёт самый высокий ребёнок — сейчас пилюля
(`py-5` + line-height 1.2 ≈ 64px), отсюда `--nav-height: 113px`. Токен читают
`smooth-scroll.tsx`, `scroll-panel.tsx` и `globals.css`. **Марку держать ≤64px**
(`h-11` десктоп / `h-9` мобайл — при 2.7:1 это ~120px в ширину), а **после реализации
замерить `document.querySelector('.nav-bar').offsetHeight`** и при расхождении обновить
токен. Пропустить замер = баг, который вылезет только при клике по пункту меню.

`nav.brand` из `content.ts` не удалять — нужен для `aria-label`, копирайта и метаданных.

**Фавикон — три настоящие поломки:**
1. `app/favicon.ico` — дефолт от create-next-app; по файловой конвенции App Router он
   отдаётся как `/favicon.ico` и перебивает всё, что объявлено в `metadata`. Заменить
   его байты на `public/favicon/favicon.ico` — **не удалять** (иначе `/favicon.ico`
   станет 404, а браузеры его запрашивают безусловно), и нельзя держать `favicon.ico`
   в корне `public/` одновременно с `app/favicon.ico` — Next падает на конфликте.
2. `public/favicon/site.webmanifest`: иконки прописаны как `/android-chrome-*.png`,
   а лежат в `/favicon/` → пути не резолвятся. `name`/`short_name` пустые,
   `theme_color`/`background_color` = `#ffffff` вопреки контракту → `#e5e5e5`.
3. `app/layout.tsx`: добавить в `metadata` поля `manifest` и `icons`.

Футер: заменить текстовую марку на тот же `.brand-mark` (`h-14`, `text-carbon`).
